## 实际改动

- 环境所有权与健康状态分离。所有权记录绑定管理根、任务和解析后的实际目录；环境准备、
  重建候选解析、空间统计及显式清理共用路径边界检查，拒绝 `..`、管理根本身、未登记目录、
  符号链接及 Windows junction。健康失败时保留旧目录，在新登记目录重建并优先解析健康候选。
- pytest 收集与执行各自生成带格式版本、运行 ID、阶段、完成状态、退出码、node ID、阶段报告、
  收集异常和实际源码导入路径的审计。普通资格要求两份审计均完整，执行审计要求每个收集节点
  具备 setup/call/teardown；空、残缺、过期或与进程退出码冲突的报告全部 fail closed。
- pytest 显式使用 checkout 内配置，缺少配置时使用独立空配置，并清除继承参数及外部插件注入。
  实际 pytest 进程记录目标包及子模块位置，拒绝环境安装副本或另一 checkout 的源码。
- node ID 只规范化 `::` 前的路径，参数标识原样保留。受审查收集失败要求唯一结构化异常与配方
  的入口、异常类型、模块和符号一致；混合异常不得资格化。
- CLI 与实验入口共用已登记环境解析逻辑；现有 CLI 参数保持兼容。旧结果仍可读取，但缺少新版
  审计时不能取得新资格。
