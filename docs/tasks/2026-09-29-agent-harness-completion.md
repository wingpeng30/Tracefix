# TraceFix 下一阶段：可信任务生命周期

状态：2026-09-29 已批准的执行计划。按 A→B→C→D 分批实现、验收、提交与推送；每批保持可运行成果。当前基线为 `1bc3e50a3dd9ffd61d1b14061c32fc6949aa12a1`，现有 PR #1 对应普通仓库首批，应独立收尾。

## A：任务事实与安全恢复

首版只支持本机、本地后端、原 checkout 与运行目录完整且身份一致的恢复。版本化快照保存任务约束、完整消息、Agent 阶段与失败恢复状态、预算、上下文与 Skills 身份、工具定义及 Repo Map 身份。工具确认的事实引用调用和源码身份；模型推测不能成为已验证事实。测试证据绑定补丁、测试目标及环境；源码变化使旧结论失效。恢复时清空只读缓存，但保留去重、Skills 额度与有效事实。

完整工具批次后原子保存 checkpoint；请求和工具执行记录开始、结束与结果。快照之后若有未决或无法归入已提交批次的记录，`inspect` 显示阻断原因，`resume` 拒绝自动继续或重放。检查 TraceFix、配置、工具、Skills、checkout、源码及测试环境身份；使用进程锁防止并发恢复。预算跨段累计，未知费用保持未知。新段保留旧轨迹，不覆盖。入口为 `tracefix inspect --run … [--json]` 与 `tracefix resume --run …`，报告展示事实、失效和恢复段。验收使用离线模型，在补丁、测试、请求、快照写入等边界故障注入，并在仓库外安装验证。

## B：普通用户路径与模型验收

把 CLI、环境和 TOML 收敛为脱敏有效配置；扩展预算、上下文、请求视图和 Skills。提供 `doctor --prepare`，临时 checkout 中复用 Runner 环境准备和导入探针，零模型构造／请求。验证平铺及 `src/` 项目和错误布局。提供显式审核的本地 Skills 目录及身份记录。普通运行增加新 checkout 独立验证，结果绑定补丁与环境身份。诊断模式记录实际请求视图；供应商 usage／费用未知明确展示。先用离线响应和故障场景验证链路；真实模型小额验收在场景、模型、次数、预算与停止条件冻结并取得付费授权后进行。

## C：可选只读 MCP

固定官方 SDK、许可证、版本与依赖哈希；首选 Serena 的符号概览／查找／引用。仅注册显式白名单，以服务名前缀避免冲突。服务在只可见任务源码快照的隔离环境运行，绑定当前 checkout／补丁身份；源码变化后使旧索引失效。复用 ToolRegistry 的参数、调用 ID、限时、限量、错误和轨迹契约；Runner 负责会话关闭与清理。若 Serena 持续两小时阻塞，记录证据并采用基于现有 AST 索引的只读 MCP 服务，明确引用候选的语义边界。必须验证真实服务及实际有用途的查询。

## D：普通仓库 Docker

新增独立于冻结任务的普通仓库 profile。以固定镜像 digest、Dockerfile／依赖哈希和解释器身份为契约；显式准备依赖，运行时无自动联网安装。容器无网络、非 root、无宿主源码挂载或 Docker socket，并有 CPU／内存／进程和临时空间限制。复用 bridge，独立容器运行与验收，记录产物和清理结果。超时、断连及 daemon 不可达时保留身份与明确诊断，不自动重放未知调用。Linux CI 验证重复运行、失败及资源清理；Windows Docker Desktop 未实测前单列未验证。

Windows Python 3.11／3.12、纯 pytest 覆盖率 ≥90%、Ruff、compileall、Diff、editable／仓库外 wheel 与现有 Linux Docker CI。保存执行提交、任务及环境身份、配置、原始日志、退出码与哈希。零供应商调用是默认；不访问 20 道留出题，不改历史评分／账本。真实模型、离线回放和合成任务结果分别表述。每批独立 PR，最多两个 GPT-6 Luna low 子代理仅用于独立审查或故障测试。
