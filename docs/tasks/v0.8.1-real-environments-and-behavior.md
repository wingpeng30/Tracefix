# V0.8.1：真实任务环境与可信行为验收

本轮新增 `prepare-real-environments`，为每道真实任务创建或复用独立虚拟环境，使用清华
PyPI 镜像安装依赖，并保存解释器、依赖指纹、安装命令和诊断日志。解释器通过 `--python`
显式传入；历史仓库不兼容当前 Python 时记录 `incompatible`，不自动修改系统 Python。

`validate-real-behavior` 现在为 base 与 gold 副本追加 JUnit 输出，区分断言失败、收集错误、
依赖错误、零测试、超时和执行错误。只有 base 出现实际断言失败且 gold 在同一测试入口通过，
任务才具备后续 LLM 预筛选资格。单题环境或执行失败会写入汇总并继续处理其他任务。

本轮不调用模型。完整环境、克隆副本、安装日志和运行输出保存在 `runs/`；只提交代码、
中文说明与脱敏汇总。
