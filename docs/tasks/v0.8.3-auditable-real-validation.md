# V0.8.3：可审计的真实任务验收

本版修正了 V0.8.2 把所有非零 pytest 结果粗略归为业务失败的问题。每个真实任务现在将构建、
收集与执行分开记录：参数列表、工作目录、退出码、超时、耗时和完整 stdout/stderr 均保存在
当前 `runs/` 副本的 `.tracefix-validation/` 下。结果 JSON 只引用这些路径，避免把大量日志或
可能的敏感环境内容提交到仓库。

验收执行器不再把参数化测试拼回 Shell 字符串，而是直接把 argv 传给 pytest。临时 pytest 插件
记录收集及 call 阶段的 node ID、各阶段结果与 xfail 状态；JUnit、退出码、node ID 和源码导入
探针共同验证 base/gold 是否使用了相同的目标集合和各自的源码副本。

失败分类新增 `permission_error`、`network_error`、`collection_error`、`selector_mismatch`、
`dependency_error`、`report_missing` 与 `skipped_or_xfailed`。pytest 缓存写入警告不会误判为
环境权限故障；真实 `Permission denied` 和代理连接拒绝则单独保留。

配方修正为：历史 pytest 任务使用现有 Python 3.11，而非不兼容的 3.12；Sphinx 10449 经逐题
审查后允许 Windows 验证。10323 保留上游 Windows xfail；10435 依赖 LaTeX 工具链，保留给
Linux 验证。本版不下载新的 Python 大版本、没有调用 LLM。

复现示例：

```powershell
.\.venv\Scripts\python.exe -m tracefix.cli validate-real-behavior `
  --tasks benchmarks/real_candidates `
  --source-root runs/real-candidate-validation-v080b `
  --test-env-root runs/real-candidate-test-envs-v083 `
  --output-dir runs/real-candidate-behavior-validation-v083-rerun `
  --recipes benchmarks/real_recipes `
  --task-id pytest-dev__pytest-10051
```

实际的逐题资格结论与边界见
[`v0.8.3-real-environment-validation.md`](../experiments/v0.8.3-real-environment-validation.md)。

验证方面，环境、验收与 CLI 的核心回归为 `30 passed`；Ruff、compileall 与 diff 检查通过。完整
206 项 pytest 覆盖率命令仍会在 `test_benchmark.py` 后留下未退出的 Python 子进程，已保存为
Windows/Codex 会话基础设施问题并中止；本版不将全量覆盖率声称为已通过。
