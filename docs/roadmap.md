# TraceFix 路线图

TraceFix 的目标是在固定模型和预算下，通过代码检索、上下文管理和测试反馈，减少真实 Issue
修复的输入 Token 与耗时，同时维持或提高独立验收成功率。

| 阶段 | 状态 | 验收门槛 | 证据与下一步 |
| --- | --- | --- | --- |

| 上下文压缩、行动效率、Repo Map | 已完成基础实现 | 可关闭模块、离线检索对照 | 12 题 Repo Map Hit@5 75%，MRR 0.465 |
