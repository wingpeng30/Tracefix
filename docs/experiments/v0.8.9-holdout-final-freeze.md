`20260921` 和预先冻结的仓库内顺序，最终取得 20 道普通资格任务：pytest、Pylint、Sphinx、

服务 502；pytest-7982 因 Windows 符号链接权限保留为平台阻塞；Sphinx-9229、7985 未入选，随后严格

node ID 和执行时依赖指纹。
