# V0.8.3：真实任务环境资格重验

这是一次不调用 LLM 的离线行为资格重验，不能解释为 Agent 修复成功率。固定候选、base commit、
gold/test patch 仍来自 SWE-bench Verified 工件；完整日志、JUnit 与审计插件输出保留在本机
`runs/`，脱敏机器可读汇总位于
[`benchmarks/experiments/v0.8.3-real-environment-validation.json`](../../benchmarks/experiments/v0.8.3-real-environment-validation.json)。

资格规则为：base/gold 收集并执行同一组 node ID；base 出现业务断言失败；gold 全部通过；不得有
skip、xfail、xpass、超时、环境错误或缺失报告。

| 任务 | 结果 | 解释 |
| --- | --- | --- |
| pylint-4551 | 不合格 | base 收集时导入 gold 才新增的符号 |
| pylint-4604 | 不合格 | base 收集时导入 gold 才新增的常量 |
| pylint-4661 | 合格 | Python 3.10，base 断言失败，gold 通过 |
| pytest-10051 / 10081 / 10356 | 合格 | 改用已有 Python 3.11 后均完成 base/gold 闭环 |
| sphinx-10323 | 待 Linux | 上游明确标记 Windows xfail |
| sphinx-10435 | 待 Linux | LaTeX 工具链依赖，未在 Windows 伪造通过 |
| sphinx-10449 | 合格 | 经逐题审查，在 Windows Python 3.11 完成闭环 |
| requests-1142 / 1766 | 合格 | Python 3.9，base 断言失败，gold 通过 |
| requests-1724 | 不合格 | 当前选择的 base 测试已通过，未复现 Issue |

结果为 **7/12 合格**，已经超过真实 C/T 付费实验要求的三题最低门槛。此前 Requests 日志中的
`ProxyError` 被保留为网络环境证据；新版精确选择器重验中 1142 和 1766 不再触发该外部路径。
后续付费实验必须只使用本表的七道合格任务，并在实验配置中固定本版代码、配方哈希、解释器和
依赖指纹。
