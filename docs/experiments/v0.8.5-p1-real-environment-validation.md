base 后、gold 后的依赖指纹。指纹漂移、报告残缺、目标集合不一致或源码不在 checkout 内都会取消资格。

## 配方与环境

- Requests 使用 Python 3.9.21，Pylint 使用 3.10.20，pytest 与 Sphinx 使用 3.11.16。
- 所有依赖经 `https://pypi.tuna.tsinghua.edu.cn/simple` 安装；创建前可用空间约 55.8 GiB，满足 10 GiB 门槛。
- pytest 三题固定 `pytest==7.1.2`、`setuptools-scm==6.4.2`。版本文件只在环境构建副本生成；该副本通过只读 `gitdir` 指向固定源码的 Git 元数据，固定源码、base 和 gold checkout 均未被修改。
- Sphinx-10435 使用 `html5lib==1.1`、`Pygments==2.11.2`。10449 的项目安装依赖已经完整记录在本轮环境指纹中，未发现需要额外配方依赖的运行缺口。

Pylint-4551 的官方参数化 node ID 不完整，配方保留函数级替代选择器。gold 实际展开为 18 个 node ID：
2 个 `test_dot_files`、4 个 `test_get_visibility`、4 个 `test_get_annotation_annassign`、6 个
`test_get_annotation_assignattr` 和 2 个 `test_infer_node`。这扩大了参数实例集合，不能声称恢复了单一
官方参数标识。4551 与 4604 的 base 收集异常都分别匹配配方中登记的测试入口、ImportError、模块和符号；gold 完整运行目标集合后通过。
