# V0.7.1：Pylint Token 行动优化冒烟对照

## 目的

确认 V0.7.1 的验收字段和 Token 行动策略能在同一真实任务上产生可审计的 C/T 行为差异，而不是评估成功率。该实验只有一条开启组和两条关闭组，样本量远小于正式配对实验要求，不得作为准确率或成本的统计结论。

## 固定条件

- 任务：`pylint-dev__pylint-8898`。
- 模型：`deepseek/deepseek-v4-flash`。
- 单次累计输入上限：120,000 Token；最大 18 步、5 次 Agent 测试。
- 上下文软阈值：32,000 Token。
- 每次都运行 Agent 不可见的隐藏验收，并记录测试文件修改。

首条 C 的累计输入为 131,452 Token，搜索 15 次、读取 10 次，也因预算中断。关闭组自身的差异说明模型采样波动显著，不能把单个 C/T 差异归因于策略。

## 结论

这组冒烟运行只支持两条工程性结论：

1. 新字段没有把最后一次自选测试误标为公开测试：这些任务的 `public_tests_passed` 均为 `null`，`independent_tests_passed` 独立记录为 `false`。
2. 开启策略后，模型在此样本中减少了搜索并至少进入一次测试，但没有在固定预算内完成修复，准确率没有改善证据，累计 Token 也没有节省证据。

正式实验前必须先清理并提交 TraceFix 工作树，然后按 C/T、T/C、C/T 交替运行每题至少三次。
