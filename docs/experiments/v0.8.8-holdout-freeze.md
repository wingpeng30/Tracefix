`78f471bf655a3137b2e8a75af1501690ec009ec3`，固定种子为 `20260921`，并排除此前已经审查的

失败环境和替补尝试均保留在本机原始记录中。

严格 base/gold 行为验收实际完成 19 道，仅 4 道取得普通资格：

- Requests：`psf__requests-5414`、`psf__requests-6028`；
- Pylint：`pylint-dev__pylint-6386`、`pylint-dev__pylint-8898`；
- pytest、Sphinx：本轮均为 0。

其余 15 道在收集阶段被环境兼容性阻塞，主要因为历史项目运行在 Python 3.12 及过新的测试依赖；
另有 Requests 2.3/2.4 和 Pylint 2.15 候选在项目安装阶段失败。Requests 候选已耗尽，Pylint 候选
也已全部尝试。当前冻结结果为 4/20，缺口 16；它是失败证据，不是完成的 20 题留出集，也没有用于
任何 Agent 成功率结论。后续需要先冻结逐题 Python 版本和依赖配方，再在新环境中重验受影响任务。

两道既有合成长上下文任务已经独立冻结并通过确定性回放。`long_policy_window` 的控制视图峰值为
49,919 个本地估算 Token，开启上下文管理后为 9,940；`long_route_normalization` 分别为 51,500 和
13,165。两题均生成 24 份契约、base 失败、gold 通过并触发折叠。该集合只验证机制，不进入真实
留出集效果估计；本地估算也不等同于供应商计费 Token。
