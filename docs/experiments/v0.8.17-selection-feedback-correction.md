起点为 `a998918`。本轮只更正 Agent 的测试反馈，不改 V0.8.15 的 48 项独立验收评分，也不调用付费模型或使用 20 道留出任务。原先 `pytest -k` / `--deselect` 后的审计仍把全部收集节点当作执行节点，导致通过的测试被报告为无效。独立 fixture 先复现了这一误判；新版 Agent 审计同时保存完整收集集合与 pytest 最终执行集合，仅对后者核对 JUnit 数量、内嵌 node ID 及 setup/call/teardown。空执行集合、重复节点或阶段、缺失阶段、额外报告和全 skip 继续拒绝。

更正范围是**单次 Agent 工具反馈**：上述 17 次应从 `invalid_test_run` 变为 `passed`。试次 4 和 29 后续仍有真实目标测试失败；试次中后续的补丁变化也会让较早的通过证据失效。不能把 13 个试次一概标为“已验证”，更不能把 17 次调用算作新增修复成功。原独立验收仍为普通开发题 C 15/24、T 12/24，T−C 为 −3；结果只说明旧反馈不可靠，尚不能证明闭环策略能提高成功率。
