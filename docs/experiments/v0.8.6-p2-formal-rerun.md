# V0.8.6 P2 正式 C/T 重跑

协议记录的工作区提交为 `dd2d23872c4829cbe49d4049606553386451aa57`；其中运行源码与已验证的
`e464f9b312bc6f075e8beec79ddd6981a5dfc1d4` 相同，提交差异仅为文档。实验使用 DeepSeek 官方
`deepseek-flash`，关闭思考、temperature 0；10 道 P1 合格任务各运行 C/T 三次，顺序为
C/T、T/C、C/T。C 同时关闭行动优化、Repo Map 和上下文压缩，T 同时开启三项并使用 32k 阈值。

60/60 个计划位置均保存了独立验收。后续离线诊断确认其中有 1 次 Windows 账本写入基础设施事故，
另有 17 次正常预算停止和 1 次单请求上界停止；因此此前“基础设施失败为 0”的表述无效。控制组独立验收成功 8/30，实验组成功 7/30；差值为
-3.33 个百分点。8 道普通资格任务中 C 为 8/24、T 为 7/24；两道受审查收集失败任务两组均为
0/6。按任务和重复序号配对时，双方同时成功 6 对。该结果是 Agent 修复成功率，不是 P1 的任务资格率。

实验组累计输入 6,084,821 Token，比控制组 6,255,579 少 170,758（-2.73%）；累计输出
89,769，比控制组 81,373 多 8,396（+10.32%）。实验组 Agent 用时 1,312.734 秒，比控制组
1,398.596 秒少 85.862 秒（-6.14%）；独立验收用时分别为 192.012 和 188.470 秒。

实验本身按高峰、输入全部未命中的保守价格计算为人民币 26.049936 元，T 比 C 少 0.274348 元
（-2.08%）。加上账单确认的历史费用和真实探测，共享账本累计人民币 29.29554120 元，无预留、
未知请求或停止原因。供应商响应记录合计 1,094 个，包含探测；其中输入 12,340,420、输出
171,146 Token，输入缓存命中 11,491,432、未命中 848,988。最终供应商账单尚未生成，因此上述
实验费用是保守计算值，不表述为实际扣费。

恢复运行复用 60/60 项，请求数保持 1,094，Agent 运行目录保持 60。原始证据在
`runs/p2-formal-deepseek-rerun-20260921/`，共享账本在
`runs/p2-formal-campaign-20260921/cost-ledger.json`；这些包含本机轨迹，不提交。脱敏数据位于
`benchmarks/experiments/v0.8.6-p2-formal-rerun.json`。

成功率从 26.67% 降至 23.33%，输出 Token 增加 10.32%。当前不能声称在维持成功率的同时获得稳定
Token 收益。离线诊断进一步确认两组上下文折叠均为 0，输入差异不能归因于压缩；T 组实际启用了
Repo Map 和工具结果精简。32 个测试修改拒绝中有 28 个同时包含产品源码与回归测试，暴露了提示与
严格验收规则不一致。详见 [`v0.8.6-p2-formal-diagnostic.md`](v0.8.6-p2-formal-diagnostic.md)。
