# V0.3.2 多文件任务离线验收

## 验证问题

这不是模型能力实验，而是基准夹具验收，回答三个问题：任务初始状态是否确实失败、标准补丁
是否可应用、公开与隐藏约束是否都能被一个合理实现满足。

## 方法与结果

- 日期：2026-09-10
- 任务目录：`benchmarks/context_tasks/`
- 任务数：4
- 每题流程：创建独立 Git 仓库 → 运行公开 pytest → 应用 `gold.patch` → 注入隐藏测试 →
  同时运行公开与隐藏 pytest。
- 初始失败：4/4
- 标准补丁成功应用：4/4
- 标准补丁后公开 + 隐藏测试通过：4/4
- 真实模型调用：0；Token 和 API 费用均为 0

机器可读记录见
[`benchmarks/experiments/v0.3.2-fixture-validation.json`](../../benchmarks/experiments/v0.3.2-fixture-validation.json)。

## 能说明与不能说明的内容

结果证明四道题定义自洽、答案不是只适配单个公开断言，且隐藏测试不会提前进入 Agent 工作区。
它不能证明 DeepSeek 能解决这些题，也不能证明上下文压缩有效。下一步应在相同 commit、模型、
预算和任务哈希下分别关闭/开启压缩，并启用请求视图审计早期事实是否保留。
