## 决策

**不采纳工具输出呈现配置，保留全部关闭的基线。** 输入 Token 减少，但 Agent 时间增加，普通题独立验收成功率未高于同期基线；并且 2 个位置未取得完整有效验收证据。这不满足预注册采纳规则。该结果是 10 道开发题上的探索性 C/T 证据，不证明更广泛任务上的节省或成功率非劣。

20 道冻结留出集保持未使用；当前没有通过规则并冻结的新配置，因此不启动留出评测。下一步应先离线追查 pytest-10051 两项验收证据缺口及其完整失败输出，确认是否属于验收环境/任务配方还是有效业务失败；不重跑付费模型、不修改历史评分。即便处理该证据缺口，现有 T 组 Agent 时间增加仍意味着不能据本轮结果直接选取该处理配置。
